# tech-demos

Sticky monorepo for daily public-tech demos.

Each approved X-bookmark pick lands in `apps/<slug>/`. Cursor cloud agents open one PR per pick with screenshot + video validation.

**Demo the pick the way you’d use it.** Agent skills and GitHub tools get a real install + real agent prompt + real output — not a lookalike playground. Libraries get a thin Bun vertical slice.

# tech-demos

Sticky monorepo for daily public-tech playground demos.

Each approved X-bookmark pick lands in `apps/<slug>/` as a self-contained Bun app. Cursor cloud agents should run on **Cursor Auto** (not Fable 5) and open one PR per pick with screenshot + video validation from the running app.

See `AGENTS.md` for agent rules, including the model requirement and common failure modes to avoid.
